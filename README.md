# session-handoff

Навык Claude Code: передача работы следующей сессии.

Сессия кончается по своим причинам (контекст, время, конец дня), а работа — нет. Всё,
что следующая сессия узнает о проделанном, она узнает из репозитория. Навык описывает,
как написать файл-задание, по которому можно начать работать через десять минут после
старта, и как подхватить его автоматически.

Главное, что он держит, — связка **«что сделано → чем это доказано»**. Без неё
следующая сессия не отличает «сделано и замерено» от «написано, но ни разу не
запущено», и либо переделывает готовое, либо полагается на непроверенное.

## Состав

| Файл | Что это |
|---|---|
| `SKILL.md` | Методология: где лежит задание, восемь обязательных разделов и почему каждый из них там есть |
| `assets/handoff-template.md` | Скелет файла-задания |
| `hooks/session-handoff-context.py` | Хук `SessionStart`: находит задание в текущем проекте и подкладывает его в контекст |

## Установка

Положить каталог в `~/.claude/skills/session-handoff/`.

Хук (необязательно, но он и делает задание по-настоящему рабочим) — в
`~/.claude/settings.json`:

```json
{
  "hooks": {
    "SessionStart": [
      { "hooks": [ { "type": "command", "command": "python \"<путь>/session-handoff/hooks/session-handoff-context.py\"" } ] }
    ]
  }
}
```

Хук ищет `docs/_prompt-next-session.md` (и типовые альтернативы: `docs/HANDOFF.md`,
`HANDOFF.md`, `docs/_handoff.md`, `.claude/handoff.md`), поднимаясь от текущего
каталога до корня репозитория. В проектах без такого файла он молчит и никогда не
роняет старт сессии.

## Проверено прогоном

* проект с заданием → контекст отдан, кириллица цела;
* сессия открыта на подкаталоге (`apps/web`) → задание найдено в корне репозитория;
* `source: "compact"` → добавляется отдельная строка о переориентировке после сжатия
  контекста;
* каталог без задания → **пустой вывод** (отрицательный контроль).

`SessionStart` выбран не случайно: `additionalContext` поддерживают `SessionStart`,
`UserPromptSubmit`, `PostToolUse`/`PostToolBatch` и `Stop`/`SubagentStop`, но не
`PreCompact` — там схема отвергает такой ответ молча.
